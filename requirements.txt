# Sizzle (local-GPU edition) - application dependencies.
#
# NOTE what is NOT in here:
#   torch / torchaudio  -> installed separately from the CUDA wheel index, because
#                          PyPI's default torch is CPU-only and would silently give
#                          you a machine that cannot render. install.bat runs:
#                            uv pip install --index-url \
#                              https://download.pytorch.org/whl/cu132 torch==2.13.0+cu132
#                            uv pip install --index-url \
#                              https://download.pytorch.org/whl/test/cu132/ torchaudio
#                          cu132 wheels cover Blackwell (sm_120) and older cards.
#   ltx-core / ltx-pipelines -> installed editable from the LTX-2 checkout:
#                            uv pip install -e LTX-2/packages/ltx-core \
#                                           -e LTX-2/packages/ltx-pipelines
#                          They pull transformers, safetensors, accelerate, av,
#                          openimageio and friends themselves.
#   ffmpeg              -> a system install on PATH, ideally an NVENC-enabled build.
#
# There is no fal-client and no cloudinary any more: this build makes no render
# API calls and hosts no media anywhere.
